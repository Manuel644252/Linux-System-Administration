Este foi outro projeto que desenvolvi no decorrer do CTeSP em Redes e Sistemas Informáticos, na unidade de Administração de Sistemas Linux, na ESTIG - Instituto Politécnico de Beja.

O objetivo era montar, em ambiente virtualizado (GNS3), uma infraestrutura de servidor baseada em CentOS 7, capaz de disponibilizar os serviços essenciais de uma rede local:

- Servidor DNS (BIND), com zona direta e inversa
- Servidor DHCP para atribuição automática de IPs
- Partilha de ficheiros via Samba, com autenticação por utilizador
- Acesso remoto via SSH
- Scripts em bash para monitorização e backup incremental, agendados via crontab

Foi um bom exercício de administração de sistemas Linux do início ao fim: desde a configuração de rede até à automação de tarefas, passando pela segurança dos serviços expostos.
